## Implemented behavior

- Input: B.1 stream, one `TKEEP=0x00FF` 8-byte nonce prefix beat followed
  by 77 full 128-bit ciphertext/tag beats.
- Authenticated body size: 1240 bytes.
- Slot size and stride: 1280 bytes.
- Slot bytes `0..1239` contain the B.1 body; slot bytes `1240..1279` are
  explicit zero transport padding. B.3 sends all 1280 bytes with UDP GSO;
  the PC discards the final 40 bytes before authentication.
- Ring test configuration: 16 slots. RTL default: 2048 slots.
- AXI DDR writes: 64-bit data, 16-beat maximum bursts.
- Slot write geometry: 160 64-bit words, exactly 10 full bursts per slot.
- Input capture geometry: 155 body words plus five generated zero words.
- Control block:
  - `CTRL_BASE + 0`: PL-published `produce_idx`.
  - `CTRL_BASE + 4`: PS-owned `consume_idx`, refreshed by PL periodically and
    immediately when the cached value indicates a possible full ring.
- Publication ordering: packet data is written first; `produce_idx` is
  published only after the final data burst B response.
- Normal control-read cadence: one consume-index read per 32 published
  packets, with an additional read before a possible full-ring decision.
- Full-ring behavior: input packet is drained to TLAST without any DDR write;
  one drop counter increment is made per dropped packet.

Command path:

```text
xvlog DDRRingWriter.sv DDRRingWriter_wrapper.v tb_ddr_ring_writer.sv
xelab tb_ddr_ring_writer
xsim b2_ring -runall
```

Result:

```text
B2_RING_TB PASS

 drain phase publications:       10000
 drain phase data bursts:       100000
 verified ring slots:              2048

 AXI memory model errors:             0

```

The first phase published 10,000 packets with the consume index advanced by
memory-model software. It issued exactly 100,000 data bursts, used periodic
control reads, and verified all 2048 ring slots. The second phase froze the
consume index, filled the ring, and forced whole-packet drops. No partial-write
or AXI error occurred.
The final run checked all 40 padding bytes in every verified slot and checked
every data burst for 4 KiB and slot-boundary safety.

The final displayed source count is from the second phase because the test
source counter is reset for each phase. The first phase was separately gated
on `complete_count >= 10000` and passed its publication and slot checks.

## Test 2 — real B.1 -> B.2 chain

The test chain is:

```text
HDMI_Axis_Packetizer
  -> AES_GCM_Session_Sequencer
  -> AXI_AES_GCM_Stream
  -> NoncePrefixInject (B.1)
  -> DDRRingWriter (B.2)
  -> AXI DDR/control-block memory model
```

Run result:

```text
B1_B2_CHAIN_TB PASS
 AES/raw packet checks:          100 packets, 0 errors
 B.1 injected packets:            100
 B.1 injected bytes:          124000
 B.2 ring publications:           100
 B.2 control-block reads:           7
 AXI memory-model errors:           0
 B.2 byte mismatches:               0
 B.2 zero-padding mismatches:       0
 AXI 4 KiB boundary errors:         0
 slot geometry errors:              0
 data bursts:                    1000
 output stalls exercised:       8209 cycles
```

For every packet, the checker compared all 1280 bytes of the final DDR
slot against the B.1 stream plus the required zero tail:

```text
slot[0..1239]    == 8-byte nonce prefix + 1232-byte ciphertext/tag
slot[1240..1279] == 40 zero bytes
```

All 100 packets matched, including the padding tail. The test applied
backpressure through the ring writer and still produced no packet loss, byte
error, or writer fault. The packetizer nonce checker also verified that the
encrypted-body header nonce matched the injected prefix sequence.

## Required corrections found during B.2 testing

These were testbench errors, not final RTL failures:

1. The first source model generated 155 AXI beats instead of the B.1 format's
   78 beats. The writer correctly reported `FAULT_LENGTH`.
2. The source model stopped one packet early due to an off-by-one condition.
3. The first slot checker compared slot 0 with packet 0 after the test ring
   wrapped. The corrected checker uses the recorded last packet for each slot.
4. The standalone memory checker was moved after the phase to avoid a same-edge
   publication/write scheduling race.

After correction, both standalone and composition tests passed.

## Boundary for B.3

B.2 simulation proves the padded 1280-byte writer and its control protocol.
It does not prove:

- Vivado BD address-map integration.
- HP0 DDR timing or timing closure.
- PYNQ buffer allocation for a 2048-slot ring.
- Cache maintenance on the PS control block.
- UDP GSO operation using the new ring.

Those are B.3 and hardware-integration tasks. B.3 must begin by reviewing
this interface and adding the software ring allocator/consumer. No B.3 code
is included in this commit.
