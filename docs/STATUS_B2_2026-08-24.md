## Implemented behavior

- Input: B.1 stream, one `TKEEP=0x00FF` 8-byte nonce prefix beat followed
  by 77 full 128-bit ciphertext/tag beats.
- Packet size: 1240 bytes.
- Slot stride: 1280 bytes.
- Ring test configuration: 16 slots. RTL default: 2048 slots.
- AXI DDR writes: 64-bit data, 16-beat maximum bursts.
- Packet write geometry: 155 64-bit words, 10 bursts per packet.
- Control block:
  - `CTRL_BASE + 0`: PL-published `produce_idx`.
  - `CTRL_BASE + 4`: PS-owned `consume_idx`, read by PL before each packet.
- Publication ordering: packet data is written first; `produce_idx` is
  published only after the final data burst B response.
- Full-ring behavior: input packet is drained to TLAST without any DDR write;
  one drop counter increment is made per dropped packet.

```

The first phase published 10,000 packets with the consume index advanced by
memory-model software. The second phase froze the consume index, filled the
ring, and forced whole-packet drops. No partial-write or AXI error occurred.

The final displayed source count is from the second phase because the test
source counter is reset for each phase. The first phase was separately gated
on `complete_count >= 10000` and passed its publication and slot checks.

The test chain is:

  -> AES_GCM_Session_Sequencer

  -> NoncePrefixInject (B.1)
  -> DDRRingWriter (B.2)
  -> AXI DDR/control-block memory model
```

Run result:

```text
B1_B2_CHAIN_TB PASS
 AES/raw packet checks:          100 packets, 0 errors
 B.1 injected packets:            100
 B.1 injected bytes:          124000
 B.2 ring publications:           100
 B.2 control-block reads:         101
 AXI memory-model errors:           0
 B.2 byte mismatches:               0
 output stalls exercised:       7895 cycles
```

For every packet, the checker compared the final DDR slot against the B.1
injected stream. The compare included all 1240 bytes:

```text
8-byte nonce prefix + 1232-byte ciphertext/tag
```

All 100 packets matched. The test applied backpressure through the ring
writer and still produced no packet loss, byte error, or writer fault.

## Required corrections found during B.2 testing

These were testbench errors, not final RTL failures:

1. The first source model generated 155 AXI beats instead of the B.1 format's
   78 beats. The writer correctly reported `FAULT_LENGTH`.
2. The source model stopped one packet early due to an off-by-one condition.
3. The first slot checker compared slot 0 with packet 0 after the test ring
   wrapped. The corrected checker uses the recorded last packet for each slot.
4. The standalone memory checker was moved after the phase to avoid a same-edge
   publication/write scheduling race.

After correction, both standalone and composition tests passed.

## Boundary for B.3

B.2 simulation proves the writer and its control protocol. It does not prove:

- Vivado BD address-map integration.
- HP0 DDR timing or timing closure.
- PYNQ buffer allocation for a 2048-slot ring.
- Cache maintenance on the PS control block.
- UDP GSO operation using the new ring.

Those are B.3 and hardware-integration tasks. B.3 must begin by reviewing
this interface and adding the software ring allocator/consumer. No B.3 code
is included in this commit.
