## Function proved

For each AES ciphertext packet:

```text
input packet:   77 full 128-bit beats = 1232 bytes
output packet:   1 prefix beat + 77 ciphertext beats = 1240 bytes
prefix:         8 cleartext nonce bytes, TKEEP=0x00FF
ciphertext:     unchanged, TKEEP=0xFFFF
TLAST:          unchanged on the final ciphertext beat
```

The byte order was checked against the existing writer/shim format:

```text
stream byte 0 = TDATA[7:0]
stream byte 7 = TDATA[63:56]
prefix byte 0 = nonce[63:56]
prefix byte 7 = nonce[7:0]
```

## Important boundary

B.1 is proven in the full packetizer -> sequencer -> AES -> injector
simulation chain.

The B.1 test does **not** prove:

- DDR ring writes. That belongs to B.2.
- PS GSO sends. That belongs to B.3.
- Hardware timing or placement.
- Full PC authentication from the new injector output.
- Vivado BD integration. The injector wrapper is compile-checked only.

Therefore B.2 must start with its own design and simulation work. No B.2
implementation has been started in this phase.
